# MHFU Remake (PPSSPP)

Remake de *Monster Hunter Freedom Unite* (ULJM05500 + FUComplete 1.4.0) bâti sur PPSSPP v1.20.4 isolé.

- Lancer : `MHFU Remake.bat` (ISO sur `G:` par défaut ; paramètre `-Iso`).
- Au premier lancement : préréglage `preset/` appliqué ; sauvegardes propres à cette instance.
- `ppsspp/` : copie de PPSSPP v1.20.4 portable (hors Git ; zip officiel SHA-256 `a60f04eb…5163`).

Feuille de route : 1. version dédiée · 2. HD / 16:9 / 60 fps · 3. contrôles PC · 4. textures remasterisées.
