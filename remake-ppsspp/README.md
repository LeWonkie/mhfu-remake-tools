# MHFU Remake (PPSSPP)

A *Monster Hunter Freedom Unite* setup (ULJM05500 + FUComplete 1.4.0) using a separate PPSSPP v1.20.4 instance.

- Run `MHFU Remake.bat`. The default ISO drive is `G:`, and the `-Iso` option lets you specify a different path.
- On first launch, the launcher applies the `preset/` configuration. This instance keeps its own saves.
- `ppsspp/` holds a portable copy of PPSSPP v1.20.4. Install it locally from the official ZIP (SHA-256 `a60f04eb…5163`).
